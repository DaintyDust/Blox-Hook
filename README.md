# Blox Hook

Blox hook is a roblox game thats hugely inspired by the mobile game stickman hook by Madbox. I tried to recreate it since i played it alot when i was a child.
Its basically a grappling hook game where you swing from point to point and try to reach the finish.

## How To Play

1. Open the link above.
2. Create a roblox account (or login if you have one) and press **Play**
> [!IMPORTANT]  
> Your roblox account needs to be 16+ to play

| Platform   | Hook / release                 |
|------------|--------------------------------|
| PC         | `Left mouse button` or `Space` |
| Mobile     | `Touch anywhere` on the screen |
| Controller | `R2` (kinda supported)         |


## Features

- Hold to grab the nearest hook, let go to fly
- Swing physics
- Bounce pads that launch you
- 60+ levels
- Pause menu, level select and sound effects
- Works on PC, mobile and controller (kinda)

## Running it locally

> [!IMPORTANT]  
> I would recommend testing it on roblox itself since some assets are uploaded by my account and cannot be used by others in the test file. So you'll be missing some sounds and meshes.

1. Install [Roblox Studio](https://create.roblox.com/).
3. Download [BloxHookDownload.rbxl](https://github.com/DaintyDust/Blox-Hook/releases/tag/V0.1) and open it in Roblox Studio. 
4. Save the game to roblox.
5. Open the game settings: in studio go to File -> experience settings
6. Enable the studio API services (for datastores) experience settings -> Security -> Enable Studio Access to API Services
7. Press **Play** (`F5`) to test.
